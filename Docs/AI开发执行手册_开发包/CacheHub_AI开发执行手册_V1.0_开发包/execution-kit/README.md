# CacheHub AI Execution Kit

本目录是主执行手册的机器可读和可复制配套材料。

- `ROADMAP.yaml`：阶段与工作包清单。
- `AI_DEV_STATE.schema.json`：AI 断点状态文件 Schema。
- `TASK_CARD_TEMPLATE.md`：单任务执行卡。
- `PHASE_PROMPT_TEMPLATE.md`：向开发 AI 下达任务的模板。
- `DEFINITION_OF_DONE.md`：统一完成标准。
- `ADR_TEMPLATE.md`：架构决策模板。
- `RISK_REGISTER_TEMPLATE.md`：风险登记模板。
- `RELEASE_CHECKLIST.md`：发布检查。

这些文件不是新的产品功能，而是用于防止开发模型遗漏、越权或跨阶段实现。
