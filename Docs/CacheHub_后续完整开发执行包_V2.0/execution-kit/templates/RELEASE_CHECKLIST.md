- [ ] Version and changelog updated
- [ ] Capability Discovery matches implementation
- [ ] Release build passes
- [ ] Unit/integration/security/protocol tests pass
- [ ] Database fresh install and upgrade pass
- [ ] Windows/macOS/Linux matrix complete for target release
- [ ] Installer/upgrade/uninstall tested
- [ ] No P0/P1 release blocker
- [ ] Cache corruption and Provider outage fallback tested
- [ ] Benchmark evidence attached
- [ ] Docs and integration tutorials updated
- [ ] Secrets and binary artifacts audited
- [ ] Tag and release notes created
