# 单阶段执行提示词模板

请执行阶段：`{{PHASE_ID}} {{PHASE_NAME}}`

1. 阅读该阶段所有 Work Item、依赖、Gate 和停止条件。
2. 核验前序阶段 Gate 是否真实通过。
3. 从第一个未完成且依赖满足的任务开始。
4. 一次只修改一个 Work Item 的范围。
5. 每完成一个任务自动提交并推送，然后继续。
6. 阶段全部任务完成后运行：
   - Release build
   - 全部单元测试
   - 相关 SQLite/HTTP/E2E
   - 安全测试
   - 该阶段专项性能或 Benchmark
7. 生成 `Docs/ai/evidence/{{PHASE_ID}}-GATE.md`，列出命令、结果、commit 和未解决风险。
8. Gate 未通过时不得更新为 Complete。
