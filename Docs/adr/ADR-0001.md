# ADR-0001：使用 \.NET 10 和 C# latest

- 状态：Accepted
- 日期：2026-08-06
- 关联任务：P00-W003

## 背景

CacheHub 需要 C#/.NET 作为主语言，需要确定 SDK 版本和语言版本。

## 决策

使用 \.NET 10 SDK (10.0.302) 和 C# latest 语言版本。通过 global.json 固定 SDK 版本，Directory.Build.props 统一构建属性。

## 备选方案

1. .NET 8 LTS - 更稳定但缺少最新语言特性
2. .NET 10 preview - 过于激进

## 正面影响

- 最新的 C# 特性（file-scoped namespaces、record、primary constructors 等）
- 性能改进
- 长期支持到 2026+

## 负面影响与风险

- \.NET 10 是 STS 版本，非 LTS
- 部分第三方库可能尚未完全支持

## 兼容性和迁移

- 后续可平滑迁移到 .NET 10 LTS
- Directory.Build.props 中 TargetFramework 集中管理

## 验证方式

- `dotnet build CacheHub.sln -c Release` 通过
- `dotnet test CacheHub.sln` 全部通过
