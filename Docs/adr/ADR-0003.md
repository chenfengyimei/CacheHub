# ADR-0003：Context Package Manifest/Payload 分离

- 状态：Accepted
- 日期：2026-08-06
- 关联任务：P00-W006

## 背景

Context Package 是 AI_KV 的核心公共协议。客户端可能只需要查看元数据（选择了哪些文件、为什么选择、Token 预算等），而不需要下载完整代码内容。

## 决策

将 Context Package 分离为 Manifest（元数据）和 Payload（内容），分别定义 C# 类型和 JSON Schema。Manifest 包含所有复现字段，Payload 包含实际代码。

## 备选方案

1. 单一对象 - 简单但无法分离查看
2. Manifest + 流式 Payload - 复杂度过高

## 正面影响

- 客户端可先检查 Manifest 再决定是否拉取 Payload
- 支持 Context Explain（解释选择原因）
- 可复现性：Manifest 记录所有版本和策略

## 负面影响与风险

- 两个对象需要一致性保证
- 大 Context Package 需要流式处理（后续）

## 兼容性和迁移

- schemaVersion = 1，后续版本向前兼容
- 未知字段保留/忽略规则明确

## 验证方式

- ContextPackageTests 全部通过
- JSON Schema 可验证
- Manifest 可序列化/反序列化
