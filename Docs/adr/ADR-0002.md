# ADR-0002：强类型标识符使用 record 基类模式

- 状态：Accepted
- 日期：2026-08-06
- 关联任务：P00-W005

## 背景

需要 WorkspaceId、FileId、IndexSnapshotId、ContextPackageId、JobId 等标识符类型不可混用，避免在方法参数中错误传递错误类型的 ID。

## 决策

使用抽象 record `StrongId(string Value)` 作为基类，各实体 ID 为 sealed record 继承 StrongId。提供 New() 和 Parse() 工厂方法。

## 备选方案

1. struct + phantom type - 更安全但 .NET 不原生支持
2. 强类型包装器 struct - 值类型可能产生装箱
3. 每个 ID 独立实现 - 重复代码多

## 正面影响

- 编译时防止类型混用
- record 自带值相等
- 简洁的工厂方法

## 负面影响与风险

- record 继承有自动 ToString 覆盖
- 需注意 JSON 序列化

## 兼容性和迁移

- 后续可添加 JsonConverter 使序列化为纯字符串

## 验证方式

- StrongIdTests 全部通过
- 不同 ID 类型不被判等
