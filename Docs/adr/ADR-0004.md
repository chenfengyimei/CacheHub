# ADR-0004：最小 GUI 使用 ASP.NET Core 最小 Web 状态页面

- 状态：Accepted
- 日期：2026-08-06
- 关联任务：P07-W001

## 背景

P07 需要最小 GUI 让技术用户不依赖 JSON 和命令行观察核心能力。总策划案建议 Avalonia UI，但 0.1-beta 阶段引入 Avalonia 重依赖会显著增加构建复杂度。

## 决策

P07 阶段使用 ASP.NET Core 最小 API + 静态 HTML 作为 0.1-beta UI 宿主。后续 P14 完整桌面阶段再引入 Avalonia。

## 备选方案

1. Avalonia UI — 功能完整但依赖重、构建慢，0.1-beta 过早
2. Console UI (Spectre.Console) — 不够直观，无法展示文件选择和排除

## 正面影响

- 零额外 NuGet 依赖（ASP.NET Core 已包含在 .NET 9）
- 快速构建和部署
- 浏览器即客户端，跨平台无需安装

## 负面影响与风险

- 不是原生桌面体验
- 需要 loopback HTTP 服务

## 兼容性和迁移

- P14 阶段迁移到 Avalonia 时，应用服务层不变，只替换 UI 层

## 验证方式

- `dotnet build` 通过
- 浏览器访问 `http://localhost:5217` 显示工作区列表
